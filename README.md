# DXF Spec Generator

Генератор спецификаций (XLSX + CSV) из папки с DXF-файлами.

Для каждого `.dxf` в выбранной папке формируется строка таблицы:

| Исполнение | Материал | Расход, м² | Длина реза, м |
|------------|----------|------------|----------------|
| имя файла  | задаётся пользователем | габарит развёртки (ш × в) | сумма длин всех контуров |

## Возможности

- Минимальный графический интерфейс (tkinter).
- Выбор папки с DXF, ввод материала (один раз для всех деталей).
- **Расход, м²** — площадь ось-ориентированного габарита развёртки (ширина × высота, без поворота).
- **Длина реза, м** — суммарная длина режущих контуров (LINE, ARC, CIRCLE, полилинии, сплайны, эллипсы).
- Результат сохраняется рядом с DXF в двух форматах: `<папка>.xlsx` и `<папка>.csv` (UTF-8 с BOM, разделитель `;`).
- Кнопка «Открыть папку» с результатом.

## Требования

- Python 3.10+
- `ezdxf`, `openpyxl`

```bash
pip install ezdxf openpyxl
```

## Запуск

```bash
python dxf_spec_generator.py
```

Далее: **Выбрать…** → папка с DXF → ввести материал → **Сгенерировать** → **Открыть папку**.
